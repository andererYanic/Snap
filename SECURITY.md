# Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue.

Nutze stattdessen die private Meldefunktion von GitHub:
**Security → Advisories → „Report a vulnerability“** in diesem Repository.

Hilfreich sind:
- betroffene Version bzw. Commit,
- Beschreibung und Auswirkung (was kann ein Angreifer erreichen?),
- Schritte zum Nachstellen oder ein Proof of Concept.

Wir bestätigen den Eingang so schnell wie möglich und stimmen den Zeitpunkt einer
Veröffentlichung mit dir ab. Das Bedrohungsmodell steht in
[`docs/SECURITY_MODEL.md`](docs/SECURITY_MODEL.md).

## Unterstützte Versionen

Vor Version 1.0 wird nur der aktuelle Stand von `main` mit Sicherheitskorrekturen versorgt.
